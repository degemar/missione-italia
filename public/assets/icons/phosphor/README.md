# Phosphor functional icons

Functional interface icons are imported from the pinned `@phosphor-icons/react@2.1.10` package and bundled locally by Vite. No CDN is used. Phosphor Icons is MIT licensed: <https://github.com/phosphor-icons/core/blob/main/LICENSE>.

These icons are for controls and status only; they are not story illustrations, landmarks, mascots, or rewards.
